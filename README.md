# pAIcture

pAIcture is a web application designed to transform shared AI conversations into clean, portable PDF documents.

## Status

pAIcture is in an early development stage. This repository currently provides only the project foundation; conversation retrieval, parsing, document rendering, and PDF export have not been implemented yet.

## Planned platforms

- ChatGPT
- Claude
- Google Gemini
- More AI platforms in the future

## Planned workflow

`Conversation Link → Parse Conversation → Normalize Content → Render Document → Export PDF`

## Repository structure

```text
pAIcture/

├── src/        # Application source code (future)
```
